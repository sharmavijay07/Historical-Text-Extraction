## 💡 Optimization Tips by Language Type

### Ancient Texts
- Enable preprocessing ✓
- Increase contrast: 1.5-2.5
- Scale factor: 2-3
- Threshold: 100-150

### Printed Modern Text
- Preprocessing optional
- Contrast: 1.0-1.2
- Scale factor: 1-2
- Threshold: 127

### Handwritten Text
- Challenging for Tesseract
- Try extreme preprocessing
- Note: May need specialized models

### Low-Quality Documents
- Enable preprocessing ✓
- Contrast: 2.0+
- Scale: 3x
- Denoise aggressively

### Mixed Language Text
- Select all relevant languages
- Process as one
- Let engine detect boundaries
- Accuracy: Can be reduced slightly

## 🔍 Troubleshooting by Language

| Language | Common Issues | Solutions |
|----------|---|---|
| Sanskrit | "Lipi" marks hard to recognize | Increase contrast, preprocessing |
| Tamil | Character clustering | Denoise, increase scale |
| Chinese | Similar looking characters | Ensure high quality image |
| Arabic | Right-to-left issues | Should auto-detect |
| Hebrew | Diacritics missed | Preprocessing helps |
| Old languages | Low accuracy | Use preprocessing, manual review |

## 📝 Notes

- **Tesseract Performance:** Generally excellent for printed text, limited for handwriting
- **Language Mixing:** Can process mixed-language documents with multi-language selection
- **Ancient Languages:** Accuracy varies based on text preservation and script clarity
- **Preprocessing:** Critical for degraded, old, or low-quality documents
- **Custom Training:** Advanced users can train custom models for specific scripts
